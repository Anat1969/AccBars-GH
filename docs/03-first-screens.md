# מסכים ראשונים

## 1. כניסה
- שדות: אימייל, סיסמה
- כפתור כניסה
- קישור לשחזור סיסמה
- אימות דו-שלבי אחרי הכניסה הראשונה

## 2. רשימת מטופלים
- שם מטופל, מועד הסשן הבא
- מה נשאר פתוח מהסשן הקודם (נקודה אחת לכל מטופל)
- חיפוש לפי שם
- כפתור: מטופל חדש

## 3. כרטיס מטופל
- פרטים בסיסיים
- יעדים שהמטופל ביטא
- היסטוריית סשנים, מהחדש לישן
- כפתור: סשן חדש

## 4. סשן
מסך אחד שמוביל בשלבים:
1. פתיחה: מה המטופל מביא היום
2. רישום: מה קרה
3. תובנה אחת
4. תרגיל לשבוע
5. סיכום במשפט אחד
6. סשן הבא

## 5. מסך המטופל (מה המטופל רואה)
- מסר אחד מהסשן האחרון
- תרגיל אחד לשבוע
- בלי מדדים, בלי ציונים, בלי השוואות

## מצבים ריקים
- רשימה ריקה: "אין עדיין מטופלים. להוסיף מטופל ראשון."
- כרטיס ללא סשנים: "עוד לא נרשם סשן. להתחיל מכאן."

סשנים:
