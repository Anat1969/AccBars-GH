# פרומפט בנייה ל-Claude Code

הפרומפט הבא מיועד להדבקה בשיחה חדשה של Claude Code בתוך הריפו.

---

קרא את CLAUDE.md ואת כל הקבצים בתיקיית docs לפני שאתה כותב קוד.

הפעל תחילה את הפקודה:

```
uipro init --ai claude
```

עבוד לפי הסקיל end-to-end-builder, בשלבים:

1. ודא שהבנת את הברף העיצובי (docs/01) ואת האפיון (docs/02). אם יש סתירה, ציין אותה בשורה אחת והמשך עם ההנחה הסבירה ביותר.
2. הקם פרויקט Next.js (או הטכנולוגיה המתאימה לסקיל) עם RTL עברית, ואת סרגל הניווט הקבוע לפי התקן ב-CLAUDE.md.
3. הקם Supabase: טבלאות מטופל, סשן, יעד ותרגיל, עם הרשאות לפי משתמש (Row Level Security). אין לכתוב סודות לקוד; השתמש במשתני סביבה.
4. מסכים לפי docs/03, לפי הסדר: כניסה, רשימת מטופלים, כרטיס מטופל, סשן, מסך המטופל.
5. בדוק כל כפתור ומסלול. ודא שהמצבים הריקים מוצגים נכון.
6. דחוף ל-branch, פתח PR, ואחרי בדיקה ירוקה מזג ל-main.
7. מסור כתובת סופית בשורה אחת.

אם מופיעה שאלה שאפשר להכריע לבד, הכרע, ציין את ההנחה בשורה אחת, והמשך.

---
